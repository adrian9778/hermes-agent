## 一、本层目标

本层只做一件事：选一个**真实、最小、可跟读**的例子，把请求从用户输入一路追到最终响应，覆盖：

1. CLI 入口与参数解析；
2. oneshot 模式的分发路径；
3. 网关启动与会话创建；
4. 网关代理执行对话循环；
5. LLM API 调用；
6. 工具调用分发（如果发生）；
7. 会话持久化；
8. 响应回到终端。

本层只走**主成功路径**。失败、重试、压缩、并发、插件钩子、缓存失效等细节先点到为止，不展开。

## 二、选择的最小例子

例子命令：

```bash
hermes -z "hello"
```

含义：以**oneshot**（一次性）模式启动 Hermes CLI，发送一条用户消息 `hello`，等待 Agent 完成并返回最终文本后直接退出。

选择它的原因：

- 入口最短，不涉及 TUI、Electron、消息网关；
- `-z` 是顶层粘性标志（sticky flag），在 `main()` 内直接分发，不经过 `cli.py` 的 REPL 循环；
- 仍然经过真实网关对话循环（`hermes_cli/gateway_agent.py` · `GatewayAgent`）；
- 能覆盖"用户输入 → CLI → 网关 → 会话创建 → 对话循环 → LLM → 响应 → 落库 → 退出"的完整主路径；
- 如果模型决定调用工具，还能自然展示工具分发链路。

`-z` / `--oneshot` 参数定义在 `hermes_cli/_parser.py` · `build_top_level_parser` `+0`（该文件 `_KNOWN_FLAGS` 集合也登记了它）。

## 三、脱敏输入/输出

### 3.1 输入

```text
argv = ["hermes", "-z", "hello"]
oneshot_prompt = "hello"
```

### 3.2 输出（示意，实际文本由模型决定）

```text
Hello! I'm Hermes, your personal AI agent. What would you like to work on?
```

### 3.3 关键副作用

- 在 `~/.hermes/state.db` 的 `sessions` / `messages` 表中新增或更新会话记录；
- 在 `~/.hermes/logs/agent.log` 中写入 INFO 级运行日志；
- 如果发生工具调用，工具结果会作为 `tool` 消息追加到本轮消息列表；
- 进程以 `os._exit(rc)` 退出（跳过 `atexit`，防止原生扩展 finalizer 干扰退出码）。

> `HERMES_HOME` 决定上述路径。默认 profile 是 `~/.hermes`；`-p <name>` 会把它切到另一个
> profile 目录（见 [07-配置体系与环境变量](./07-配置体系与环境变量.md)）。

def _run_oneshot_from_args(args) -> None:

### 5.5 网关对话运行：`hermes_cli/gateway_chat.py` · `run_gateway_chat` `+0`

真实符号：

- 文件：`hermes_cli/gateway_chat.py`
- 函数：`run_gateway_chat` `+0`
- 作用：通过网关 RPC 创建/恢复会话，运行 `GatewayChatView`。

主路径：

1. 提取 query：`query = getattr(args, "query", None) or getattr(args, "q", None)`；
2. 若 `oneshot_prompt` 是字符串，则 `query = oneshot_prompt`；
3. 确定 `oneshot = True`（因为 `oneshot_prompt` 存在）；
4. `async with connect_gateway()` 建立 RPC 连接；
5. `client.rpc("runtime.describe")` 获取网关能力描述；
6. **创建会话**：`client.rpc("session.create", source="oneshot", **policy)`；

   - `source="oneshot"` 标记该会话为一次性运行（隐藏于人工选择器，但仍保留在 CLI 历史中）；
7. 打印会话 ID 到 stderr（`print("Session: " + snapshot["stored_session_id"], ...)`）；
8. 构造 `GatewayChatView(client, snapshot, quiet=quiet, ...)`；
9. `view.unattended = True`（因为 `oneshot_prompt` 是字符串）；
10. `await view.run(query, oneshot=True)` 执行对话并返回退出码。

### 5.12 退出：`hermes_cli/main.py` · `_exit_after_oneshot` `+0`

真实符号：

- 文件：`hermes_cli/main.py`
- 函数：`_exit_after_oneshot` `+0`
- 作用：退出 oneshot 模式，跳过 `atexit`，防止原生扩展 finalizer 干扰退出码。

```python
def _exit_after_oneshot(rc: object) -> None:
    """Exit one-shot mode without letting late native finalizers change rc.

    The SIGABRT this guards against fires in a native-extension finalizer
    during ``Py_FinalizeEx``, *after* the response printed. Flush, shut down
    file logging, then ``os._exit`` past finalization. The ``atexit`` chain is
    deliberately skipped — several handlers re-enter native code that may be
    the abort source.

    See #30387, #43055.
    """
    for stream in (sys.stdout, sys.stderr):
        try:
            stream.flush()
        except Exception:
            pass
    from hermes_cli.cpu_profile import write_cpu_profile

    write_cpu_profile()  # atexit never runs past os._exit
    try:
        logging.shutdown()
    except Exception:
        pass
    os._exit(rc if isinstance(rc, int) else (0 if rc is None else 1))
```

**关键点**：使用 `os._exit(rc)` 而非 `sys.exit(rc)`，跳过 `atexit` 钩子，防止原生扩展在 `Py_FinalizeEx` 期间触发 SIGABRT。

## 七、本层结论

读完本层，你应能回答：

- 最小例子 `hermes -z "hello"` 从哪个文件进入（`hermes_cli/main.py` · `main` `+0`）；
- `-z` 如何绕过 `cli.py` 直接调用网关（`_run_oneshot_from_args` → `launch_gateway_chat`）；
- 网关如何通过 RPC 创建会话并启动 `GatewayAgent`；
- `GatewayAgent` 如何调用 `run_conversation` 执行对话循环；
- LLM 返回 `tool_calls` 时如何分发到 `handle_function_call`；
- 消息最终如何通过 `SessionDB.append_message` 写入 SQLite；
- 响应如何回到终端（`GatewayChatView.run` → stdout）；
- 进程如何通过 `os._exit(rc)` 退出（跳过 `atexit`）。

**关键架构事实**：

1. **`-z` 绕过 `cli.py`**：`HermesCLI` 的 REPL 循环不启动，直接走网关 RPC 路径；
2. **网关代理是 `AIAgent` 的替身**：`hermes_cli/gateway_agent.py` · `GatewayAgent` 通过 `session_id` 绑定到 `SessionDB`，内部调用相同的 `run_conversation`；
3. **会话创建在网关侧**：`session.create` RPC 调用在网关进程内创建/获取会话，然后绑定 `GatewayAgent`；
4. **持久化门面是 Mixin 组装**：`SessionDB` 是 16 个 Mixin 组装，`append_message` 实际定义在 `hermes_state_messages.py` · `SessionMessagesMixin.append_message` `+0`。
