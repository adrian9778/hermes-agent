## 三、安装流程

- 使用 `hermes setup` 配置 provider/API key；
- 使用 `hermes tools` 管理工具；
- 使用 `hermes update` 更新；
- 使用 `hermes doctor` 诊断。

## 四、依赖管理

- Python 依赖；
- Node/TypeScript 依赖（TUI、Desktop、Web）；
- 插件依赖；
- 技能依赖。

## 六、运维监控
